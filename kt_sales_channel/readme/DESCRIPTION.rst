Modelo ``kt.sales.channel`` (nombre, ``code`` técnico, tipo
manual/integrado) más ``kt_sales_channel_id`` en ``sale.order`` y
``pos.order``. Canal por defecto en ``pos.config``.

Canales precargados: Local, Ecommerce, Teléfono, Correo, WhatsApp,
Mercado Libre, Falabella/Linio, Éxito, Facebook, TikTok Shop,
Homecenter, Rappi.

Reporte **Ventas > Reportes > Por canal** (pivot/gráfico).

Base de ``kt_marketplace_feed_sync`` y ``kt_marketplace_order_import``.
