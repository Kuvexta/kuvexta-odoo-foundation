Permite registrar excepciones por bodega a los interruptores de
características avanzadas de inventario de ``kt_advanced_stock_flows`` —
útil cuando una bodega específica (típicamente una bodega central
compartida entre varios establecimientos) necesita un comportamiento
distinto al configurado por defecto para la compañía.

Sin excepciones registradas, el comportamiento es idéntico al de
``kt_advanced_stock_flows`` por sí solo — este módulo es puramente
aditivo.
