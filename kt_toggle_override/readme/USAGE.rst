Una vez registrada una excepción para una bodega, el comportamiento de
``kt_advanced_stock_flows`` en esa bodega usa el valor de la excepción en
vez del valor configurado a nivel de compañía — de forma transparente,
sin ningún cambio adicional necesario en otras pantallas.

Si una bodega no tiene ninguna excepción registrada para una
característica, se usa el valor de la compañía, exactamente como si este
módulo no estuviera instalado.
